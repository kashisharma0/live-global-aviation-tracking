# Live Global Aviation and Flight Tracking

A real-time flight tracking and data processing project using Kafka, Apache Spark Structured Streaming, Parquet, and Streamlit.

## Overview

This project processes aircraft data through a distributed streaming pipeline and presents flight statistics and aircraft positions in an interactive dashboard.

## Architecture

OpenSky API → Kafka (`flights_raw`) → Apache Spark Structured Streaming → Parquet Data Lake + JSON Outputs → Streamlit Dashboard

## Features

- Flight data ingestion through Kafka
- Distributed processing using Apache Spark
- Structured Streaming with micro-batches
- Parquet storage for processed flight data
- JSON outputs for dashboard metrics
- Interactive world map showing aircraft positions
- KPIs for tracked aircraft, airborne aircraft, grounded aircraft, altitude, and speed
- Country and altitude-band charts

## Setup

### Prerequisites

- Docker Desktop
- Python
- Git
- OpenSky API credentials for authenticated data access

### Run the Pipeline

1. Clone the repository:

   ```powershell
   git clone https://github.com/kashisharma0/live-global-aviation-tracking.git
   cd live-global-aviation-tracking
   ```

2. Create a local `.env` file in the project root containing your OpenSky credentials:

   ```dotenv
   OPENSKY_CLIENT_ID=your_client_id
   OPENSKY_CLIENT_SECRET=your_client_secret
   POLL_INTERVAL=90
   ```

   Replace the example credentials with your own. Never commit `.env` or expose your secrets publicly.

3. Start the Docker services:

   ```powershell
   docker compose up -d
   ```

4. Install the producer dependencies:

   ```powershell
   python -m pip install -r producer/requirements.txt
   ```

5. Start the Spark streaming job:

   ```powershell
   .\run_stream.ps1
   ```

6. In a separate PowerShell window, install the dashboard dependencies:

   ```powershell
   python -m pip install streamlit pandas
   ```

7. Launch the dashboard from the project root:

   ```powershell
   python -m streamlit run app.py
   ```

8. Open [http://localhost:8501](http://localhost:8501) in your browser.

**Note:** The producer script uses Kafka's external listener at `localhost:9094`. Ensure the Docker Compose configuration exposes this listener. The producer must also be started separately if your workflow requires live ingestion; the Spark streaming job alone does not fetch data from OpenSky.

## Data Storage

Processed flight data is stored in Parquet format. JSON files generated by the pipeline provide the dashboard with metrics, country statistics, altitude bands, and aircraft positions.

Generated live data and local credentials should remain untracked by Git.

## Project Status

The streaming pipeline and dashboard have been tested locally with Kafka, Spark, Parquet, and Streamlit. Setup requirements may vary depending on local Docker configuration and environment variables.
