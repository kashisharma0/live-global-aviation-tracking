# Live Global Aviation and Flight Tracking

A real-time flight tracking and data processing project using Kafka, Apache Spark Structured Streaming, Parquet, and Streamlit.

## Overview

This project processes aircraft data through a distributed streaming pipeline and presents flight statistics and aircraft positions in an interactive dashboard.

## Architecture

OpenSky API → Kafka (`flights_raw`) → Apache Spark Structured Streaming → Parquet Data Lake + JSON Outputs → Streamlit Dashboard

## Features

- Flight data ingestion through Kafka
- Distributed processing using Apache Spark
- Structured Streaming with micro-batches
- Parquet storage for processed flight data
- JSON outputs for dashboard metrics
- Interactive world map showing aircraft positions
- KPIs for tracked aircraft, airborne aircraft, grounded aircraft, altitude, and speed
- Country and altitude-band charts

The dashboard displays:

- Aircraft distribution by altitude band

## Setup

### Prerequisites

- Docker Desktop
- Python
- Git

### Run the Pipeline

1. Clone this repository.
2. Configure any required environment variables locally in a `.env` file.
3. Start the services using Docker Compose:

   ```powershell
   docker compose up -d
   ```

4. Run the streaming job using the provided PowerShell script:

   ```powershell
   .\run_stream.ps1
   ```

5. Install the dashboard dependencies in your Python environment:

   ```powershell
   python -m pip install streamlit pandas
   ```

6. Launch the dashboard:

   ```powershell
   python -m streamlit run app.py
   ```

7. Open [http://localhost:8501](http://localhost:8501) in your browser.

> **Note:** Exact setup steps may depend on your local Docker configuration and environment variables.

## Data Storage

Processed flight data is stored in Parquet format. JSON files generated by the pipeline provide the dashboard with metrics, country statistics, altitude bands, and aircraft positions.
